# Графічний редактор

Мобільний застосунок для створення та редагування графічних проєктів, розроблений на фреймворку **Flutter**. Курсовий проєкт з дисципліни "Проєктування автоматизованих інформаційних систем" (Полтавський політехнічний фаховий коледж НТУ "ХПІ").

## Можливості

- створення проєктів із вибором розміру полотна (шаблони "Instagram Post", "Instagram Story", "YouTube" або власний розмір);
- список проєктів із мініатюрами, пошук за назвою;
- перейменування, дублювання та видалення проєктів;
- додавання зображень з галереї та текстових шарів;
- переміщення, масштабування та обертання шарів;
- обрізання зображень;
- малювання інструментами "Пензель" і "Гумка", окремі шари малювання;
- панель шарів: вибір, зміна порядку, показ і приховування, видалення;
- скасування та повторення дій (до 50 кроків);
- автозбереження проєктів;
- експорт результату у PNG та збереження в галерею пристрою;
- робота без підключення до інтернету.

## Технології

| Засіб | Призначення |
|---|---|
| Flutter, Dart | інтерфейс і логіка застосунку |
| SQLite (sqflite) | метадані проєктів: назва, розмір полотна, мініатюра, дати |
| Файлова система (path_provider, path) | вміст проєктів: шари, штрихи, копії зображень |
| gal | збереження готового зображення в галерею |

## Зберігання даних

Застосунок використовує комбіноване сховище:

- **база даних SQLite** (`graphic_editor.db`) містить таблицю `projects` зі списком проєктів;
- **файли проєкту** лежать у папці `projects/<id>/`:
  - `state.json` – шари та штрихи пензля;
  - `assets/` – копії доданих зображень;
  - `thumb_*.png` – мініатюра для списку проєктів.

Файл `state.json` записується через тимчасовий файл, тому попереднє збереження не пошкоджується у разі збою.

## Структура проєкту

```
lib/
├── app/         # тема оформлення
├── database/    # AppDatabase – створення бази даних SQLite
├── models/      # Project, EditorElement, BrushStroke
├── services/    # ProjectService (SQLite), ProjectStorage (файли проєкту)
└── .../         # екрани: список проєктів, створення проєкту, редактор, обрізання
```

## Вимоги

- Flutter SDK
- Android Studio (або інше середовище з підтримкою Flutter)
- пристрій або емулятор з Android 7.0 (API 24) і вище

## Запуск

```bash
# завантажити залежності
flutter pub get

# запустити на підключеному пристрої або емуляторі
flutter run

# зібрати встановлюваний файл
flutter build apk
```

Готовий файл розташовується в `build/app/outputs/flutter-apk/app-release.apk`.

Під час першого збереження зображення застосунок запитує дозвіл на доступ до галереї.

## Обмеження

- інструмент "Фігури" ще не реалізований;
- перевірено лише на Android, версія для iOS не збиралася.
